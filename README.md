# Lina Vale — UI/UX Portfolio Landing Page

A polished fictional UI/UX designer portfolio landing page with responsive layout, atmospheric canvas animation, scroll reveals, tilt cards, animated counters, mobile menu, accessible skip link and reduced-motion handling.

## Run locally

Open `index.html` directly in a browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` — semantic page structure
- `styles.css` — responsive visual system and animations
- `app.js` — interactions, canvas background, scroll reveals, counters, menu
